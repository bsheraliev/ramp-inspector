# SAFA Inspector — правила проекта

Офлайн-PWA перронной инспекции ВС для инспекторов АГА РТ. Vanilla JS, IndexedDB, сервис-воркер, GitHub Pages.
Сайт: https://bsheraliev.github.io/ramp-inspector/ · репозиторий `bsheraliev/ramp-inspector` · локальная папка `safa-inspector` (имена не совпадают).

## Порядок работы

- Правки — в ветке `claude/…`, затем запрос на слияние. В `main` сливает владелец: слияние и есть выкатка на сайт.
- При любой правке `index.html`, `app.js`, `data/*` поднимать `APP_VER` в `app.js` и `CACHE` в `sw.js` (одно и то же число).
- Превью: порт 8180 (`.preview-server.ps1`). Открывать `http://localhost:8180/?demo=1` — без пароля.

## Ворота — прогнать до слова «готово» и до запроса на слияние

1. `node --check app.js sw.js data/i18n.js data/hints.js`
2. Сквозная проверка экранов в превью (68 шагов, оба языка):

       await (await fetch('scripts/smoke.js', {cache: 'no-store'})).text().then(eval);
       const r = await SAFA_SMOKE(); r.failed + ' — ' + r.report

   Должно быть `0 — все шаги пройдены`. Упало — не «готово».
   Новый экран или окно — добавить шаг в `scripts/smoke.js`.

## Грабли

- **Не называть переменные и параметры `t`.** `t()` — функция перевода; локальная `t` её перекрывает,
  и экран падает с `t is not a function`. Так вкладка «Справочник → Формулировки» не открывалась с 1.5.0 по 1.7.0.
- Реальные находки из базы SAFA — только в зашифрованный набор `data/private.enc`
  (`scripts/build-private-pack.mjs`, пароль вводит владелец). В `photos/` и в открытые файлы их не класть.
- Тестовый `data/private.enc` перед коммитом удалять: `git checkout -- data/private.enc`.
- Строки интерфейса — через `t('…')` с ключом в `data/i18n.js`; поля данных `{ru,en}` — через `L(obj)`.
- Значения, вычисляемые при загрузке файла (константы верхнего уровня), через `t()` не пропускать: язык ещё не известен.
