# SAFA Inspector — перронная инспекция ВС (АГА РТ)

Офлайн-first PWA для инспекторов Агентства гражданской авиации при Правительстве
Республики Таджикистан. Проведение перронной инспекции воздушного судна прямо на
пероне — без интернета, с планшета или телефона.

## Что умеет

**Три вида инспекции**

| Код | Расшифровка | Объект |
|---|---|---|
| SAFA | Safety Assessment of Foreign Aircraft | ВС иностранных эксплуатантов |
| SANA | Safety Assessment of National Aircraft | ВС эксплуатантов Республики Таджикистан |
| SACA | Safety Assessment of Community Aircraft | ВС эксплуатантов государств-участников соглашения |

**Чек-лист — 53 пункта** по разделам официального бланка:
A. Лётная кабина (24) · B. Безопасность/салон (14) · C. Состояние ВС (11) ·
D. Груз (3) · E. Общее (1).
Каждый пункт: ✓ соответствует · N не применимо · ! несоответствие · – не проверялся,
плюс примечание (RMK).

**База предописанных находок (PDF) — 456 формулировок.** Инспектор выбирает готовую
формулировку по своему пункту, категория (1 / 2 / 3 / G) подставляется автоматически
и соответствует закреплённой в источнике. Ссылки на нормы (Приложения ИКАО, Part-ORO,
Part-CAT, Part-NCC) прикладываются к находке.

**Фотофиксация** — снимок с камеры прикрепляется к находке, сжимается до 1400 px /
JPEG 72 %, хранится в устройстве.

**Библиотека примеров «как хорошо / как плохо» — 155 изображений**: 141 фотопример
и 14 схем осмотра (маршрут обхода ВС, 18 зон внешнего осмотра, алгоритм
категорирования повреждений, координатная сетка привязки повреждения и др.).
Покрытие: C — 58, A — 41, D — 22, B — 18, без привязки — 16.
Примеры видны прямо в карточке пункта чек-листа и в справочнике.
Свои снимки добавляются с инспекции кнопкой ★ на фото находки — библиотека
растёт от выезда к выезду. Всё работает офлайн: в настройках есть индикатор
готовности и кнопка догрузки.

Источник справочных изображений — учебный курс EASA/GCAA (Dubai, 2015), RIM Issue 4,
курс ICAO NAU Part 1/2. Слайды несут заголовок пункта и официальную формулировку
находки, поэтому привязка к пунктам A01…E01 достоверна.

**Двуязычный интерфейс (RU / EN)** — переключатель в «Настройки → Язык интерфейса».
Английская локаль сделана для международного/СНГ+ формата премии: словарь
`data/i18n.js` (≈284 строки), англ. термины по SAFA/ICAO. Печатный бланк PI
двуязычен независимо от выбранного языка. Формулировки находок всегда на английском
(в базу SAFA вносятся дословно).

**KPI эффекта** — карточка на экране «Сводка» с измеримой пользой внедрения:
среднее время инспекции (от создания до завершения), полнота чек-листа
(средний охват 53 пунктов), доля находок с фотодоказательством, доля цифровой
сдачи в управление (безбумажный оборот). Считаются из фактических инспекций
устройства — для заявки и презентации.

**Класс принятых мер** — 1 / 2 / 3a / 3b / 3c / 3d (вплоть до немедленного запрета эксплуатации),
с подсказкой рекомендуемого класса по максимальной категории находок.

**Отчёт Proof of Inspection** — двуязычный печатный бланк A4 с шапкой АГА РТ,
чек-листом, таблицей находок, отметкой класса мер и двумя подписями (пальцем на экране).
Печать → «Сохранить как PDF».

**Синхронизация** — отправка акта в Google-таблицу управления через Apps Script;
при находке категории 3 — мгновенное уведомление в Telegram.

**Тренажёр инспектора** — 456 реальных находок как база вопросов: определить категорию,
определить пункт чек-листа, смешанный режим, разбор ошибок со ссылками на нормы.

**Сводка** — число инспекций, находки по категориям, SAFA ratio (находок на инспекцию),
самые частые пункты с несоответствиями, разбивка по эксплуатантам.

## Источник данных

База находок извлечена из **EASA Ramp Inspection Manual, Appendix 1 —
Inspection instructions and pre-described findings, Issue 6** (Doc INST.RI.01/006,
утв. 28.10.2022), 304 страницы. Извлечено 456 записей из 456 — потерь нет.

Формулировки находок оставлены **на английском языке**: в базу SAFA они вносятся
дословно. Названия пунктов, интерфейс и печатный бланк — русские (бланк двуязычный).

Перегенерация базы после выхода нового Issue:

```bash
python scripts/extract_pdfs.py <извлечённый_текст.txt> data/pdf-findings.json
```

Ссылки на нормы в v1 сведены в одну строку `refs`; в источнике их четыре колонки
(SAFA CAT / SACA CAT / SAFA GA / SACA NCC) — при необходимости разделяются в парсере.

## Вход по паролю и закрытый набор примеров

Реальные находки из базы SAFA лежат в `data/private.enc` — это один зашифрованный файл
(AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600 000 итераций). Исходные изображения,
подписи к ним и пароль в репозиторий не попадают.

- Есть файл набора — при первом запуске приложение просит пароль. Проверка пароля — это удачная
  расшифровка; сам пароль нигде не хранится. На устройстве остаётся неизвлекаемый ключ.
- Нет файла набора — замка нет, приложение работает как раньше.
- «Демо без пароля» на экране входа открывает приложение без реальных находок
  (выключается константой `DEMO_DOOR` в `app.js`).
- Настройки → Доступ → «Выйти на этом устройстве» убирает ключ и расшифрованные изображения;
  инспекции остаются.

Сборка набора (пароль вводится в терминале и на экране не показывается):

    node scripts/build-private-pack.mjs "<папка с изображениями и pack-index.json>" --publish

Пересборка с тем же паролем подхватывается устройствами без повторного входа.
Пересборка с новым паролем — все входят заново. Пароль не короче 10 знаков: файл лежит
в открытом доступе, и короткий пароль можно подобрать перебором.

Важно: окно входа защищает только то, что зашифровано. Чек-лист, база формулировок EASA
и библиотека из 155 изображений лежат в репозитории открыто, как и раньше.

## Синхронизация: развёртывание бэкенда

1. Создать Google-таблицу «Перронные инспекции SAFA — АГА РТ».
2. **Расширения → Apps Script**, вставить `gas/Code.gs`.
3. (опционально) **Настройки проекта → Свойства скрипта**: `TG_TOKEN`, `TG_CHAT` —
   уведомления о находках категории 3.
4. **Развернуть → Новое развёртывание → Веб-приложение**:
   запуск от имени **Я**, доступ **Все (Anyone)**.
5. Скопировать `/exec`-URL в приложении: **Настройки → Синхронизация**.

Листы `Инспекции` и `Находки` создаются автоматически. Повторная отправка одного акта
обновляет строку, а не дублирует её.

Отправка идёт в режиме `no-cors` — Apps Script не отдаёт CORS-заголовки на `/exec`,
ответ не читается. Признак успеха — отсутствие сетевой ошибки.

## Публикация для инспекторов

Статический хостинг (GitHub Pages / Render Static) — приложение целиком клиентское.
Инспектор открывает адрес в браузере телефона и ставит на экран через
«Добавить на главный экран». Дальше работает офлайн.

## Ограничения v1

- Фотографии остаются в устройстве: в таблицу уходит только их количество.
  Загрузка снимков в Google Drive — отдельная задача.
- Ссылки на нормы не разделены по колонкам SAFA CAT / SACA CAT / SAFA GA / SACA NCC.
- Интерфейс двуязычный (RU/EN); таджикская версия не делалась.
- Раздел E (Общее) справочными изображениями не покрыт; 16 изображений без
  привязки к пункту — привязываются вручную правкой `data/photos-pdf.json`
  и пересборкой `python scripts/build_photos.py`.
- Алкотест экипажа (тип отчёта AT в базе SAFA) не реализован, хотя Somon Air
  и Таджикистан состоят в AT Priority list.
- Нет учёта корректирующих действий (Follow up) по выданным находкам.
